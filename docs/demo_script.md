## 2. 외워둘 첫 60초 (문제 정의)

> "제조 현장에서 가장 큰 손실은 이상을 늦게 발견하는 것입니다.
> 발견해도 원인을 모르면 조치까지 또 시간이 걸립니다.
>
> 단순 예측 모델만으로는 현장 의사결정에 바로 이어지지 않습니다.
> 그래서 저희는 예측·설명·조치 세 단계를 하나의 플랫폼으로 묶었습니다.
>
> QualityLens는 공정 센서 데이터로 이상을 **예측**하고,
> SHAP으로 **원인을 설명**하고,
> 임계치 엔진이 **바로 실행할 조치**까지 제안합니다."

## 3. 시연 골든 패스 (3분간)

### Step 1 — P1 통합 대시보드 (1:45 ~ 2:30, 45초)

1. "이것이 통합 대시보드입니다."
2. KPI 4카드 손가락으로 가리키며: "총 샘플 수, 이상 판정 수, 운영 threshold, 응답 시간 10ms 미만"
3. 시계열 차트: "시간대별 이상 확률 추세입니다"
4. 우측 상위 기여 센서 5개 보여주며: "전체 평균 기준 가장 영향력 있는 센서들"

### Step 2 — P2 실시간 예측 (2:30 ~ 3:15, 45초)

1. 사이드바 P2 클릭
2. 데모 샘플 드롭다운 → **"FAIL 샘플"** 선택 (3번째 또는 4번째)
3. 게이지 차트 가리키며: "이상 확률 78%, 즉시 조치 필요"
4. "그런데 이게 왜 이상인지가 더 중요합니다 → P3로 갑시다"

### Step 3 — P3 원인 분석 (3:15 ~ 3:50, 35초)

1. 사이드바 P3 클릭
2. 좌측 전체 평균: "이 모델 전체적으로 중요한 센서들"
3. 우측 샘플별 SHAP: "방금 본 그 샘플에서는 sensor_XXX가 가장 큰 양의 기여 — 이게 이상으로 판정한 근거"
4. "이제 어떻게 해야 하는가? → P4"

### Step 4 — P4 조치 가이드 (3:50 ~ 4:20, 30초)

1. 사이드바 P4 클릭
2. "정상 범위를 벗어난 센서들이 편차 큰 순으로 정렬됩니다"
3. 첫 번째 긴급 카드 가리키며: "이 센서는 정상 범위 초과, 4σ 편차 — 즉시 공정 단계 점검 권고"
4. "예측 → 설명 → 조치, 한 화면에서 끝까지 이어집니다"
