## Q&A 빈출 질문 — 30초 답변 템플릿

### Q1: "왜 SHAP인가요?"
> "비전문가 작업자가 *'이상이다'* 만 알고 *'왜인가'* 모르면 조치할 수 없습니다.
> SHAP은 게임이론 기반으로 각 센서의 기여도를 공정하게 분해해 줍니다.
> 우리는 Top-3 센서를 자동 텍스트로 변환해 *'센서_003이 45% 영향'* 처럼 한국어로 보여줍니다."

### Q2: "왜 XGBoost? 딥러닝은요?"
> "SECOM 같은 제조 데이터는 **6.6% 불량의 극심한 불균형 + 591개 센서의 표 형식** 입니다.
> 이 환경에서 XGBoost는 딥러닝보다 정확도·해석성·학습 속도 모두 우위입니다.
> SMOTE로 클래스 균형 보강 후 5-Fold MCC 0.98±0.01 달성했습니다."

### Q3: "Western Electric Rules는 왜 추가?"
> "단일 점 한 개로 이상을 판단하는 방식은 작은 시프트를 놓칩니다.
> WER 4종 룰은 *'연속 3점 중 2점이 2σ 초과'* 같은 패턴으로 평균 이동·점진 변화를 감지합니다.
> 우리는 이를 자동화해서 *숙련도 낮은 작업자도 놓치지 않게* 했습니다."

### Q4: "안전·설비·생산 영역은 정말 통합됐나요?"
> "예 — **품질** (P1-P3 SHAP), **안전** (메인 상단 3단계 알림 배너), **설비** (P5 SPC 관리도 + WER 자동 감지),
> **생산** (P4 누적 이력 + OEE 분해) 4영역이 단일 사이드바에서 자유 이동합니다.
> 데이터 소스가 하나(timestamp + state 컬럼)로 일관되어, 한 화면 안에서 사이클이 닫힙니다."

### Q5: "중소공장이 정말 쓸 수 있나요?"
> "📤 데이터 업로드 페이지에서 **자기 공장 CSV** 한 번 올리면 즉시 추론.
> 591개 컬럼 전부 없어도 OK — 누락된 센서는 자동으로 평균값 처리.
> 인코딩도 UTF-8 / UTF-8-sig / CP949 자동 감지.
> Streamlit Cloud 1-Click 배포 — 서버 구축 비용 0."
