# 캡처 인덱스 (Captures Index)

> 작업·발표 자료용 스크린샷 버전 관리. 새 버전은 UI 변경·폰트 변경·데이터 소스 전환 또는 본선 리허설 시점마다 발행.

## 버전 목록 (신규 → 과거)

| 버전 | 시점 | 트리거 | 비고 |
|---|---|---|---|
| [v1](v1/) | _대기_ | P-B/PR-1 hotfix 머지 후 첫 캡처 (예정) | `v1/README.md` 가이드 참고 |
| [v0](v0/) | 2026-05-19 ~ 2026-05-22 | P-A 작업 중 누적된 발표·QA 캡처 (P-B/PR-2에서 이관) | slides/ + qa/ + thumbnails + test |

## 발행 규칙

1. **트리거** — 다음 중 하나에서 신규 버전:
   - UI 레이아웃 변경 (P-A PR-4 단계별 HTML 보고서 추가 등)
   - 폰트 / 컬러 / 스타일 변경 (P-C 한글 폰트 점검 후)
   - 데이터 소스 전환 (dummy ↔ real)
   - 본선 리허설 직후 (스냅샷 보존)

2. **폴더 구성** — `vN/` 안에:
   - `INDEX.md` 또는 `notes.md` — 버전 메타 (왜 만들었는지, 캡처 시각, 환경)
   - `*.png` 또는 `*.jpg` — 실제 캡처 파일
   - 카테고리가 많으면 `slides/`, `qa/`, `pages/` 서브폴더로 분리

3. **명명 규칙**:
   - 페이지 캡처: `{NN}_{page-name}.png` (예: `01_main_dummy.png`)
   - QA 캡처: `qa-{NN}.jpg`
   - 발표 슬라이드: `slide-{N}.jpg`

4. **이 INDEX 파일** — 새 버전 추가 시 위 표 맨 위에 1줄 추가. 자동화는 P-B/PR-4 대시보드 빌드 스크립트에서 일괄.
