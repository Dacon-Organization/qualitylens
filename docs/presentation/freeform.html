1. About — Quality + Lens 정체성

QualityLens는 Quality(품질)를 Lens(렌즈)로 들여다보는 투명 AI 플랫폼입니다. 기존 제조 AI의 "블랙박스" 한계를 극복해, 중소 제조 현장 작업자가 "왜 불량인가"를 즉시 이해하고 조치할 수 있게 합니다.

🎯 미션

마키나락스급 설명력을 1/100 가격으로 중소 제조에.

🛠 핵심 기술

XGBoost + SHAP + Western Electric Rules + Pareto 80/20 통합.

🚀 차별점

Streamlit 1-Click 무료 배포 · CSV 업로드 → 30초 인사이트.

2. 문제 정의 + 시장 갭

현장 페인포인트

  • 이상 알람 → 원인 파악까지 평균 6시간
  • SPC 통계 전문가 부재로 관리도 직접 못 그림
  • 마키나락스·DELMIA는 수억~수십억 도입 비용
  • Tableau/PowerBI는 BI만 — 실시간 이상감지 ❌

시장 공백 (Whitespace)

"대기업 전용 AI 솔루션" ↔ "범용 BI 도구" 사이에 중소 제조 + 설명력 있는 AI 공백. QualityLens는 이 공백을 Streamlit 기반 경량 + SHAP 설명력으로 채웁니다.

3. AI 활용 — 왜 XGBoost + SHAP + WER?

🔧 모델 선정 의사결정 트리

고려 대상적합도선정/탈락 이유
XGBoost ⭐✅ 선정591센서 표 형식 + 6.6% 극심한 불균형에 강건, 트리 기반 → SHAP 자연 결합
LightGBM대안속도 우위지만 XGBoost와 정확도 차이 미미, 익숙도 우선
딥러닝 (TabNet 등)❌ 탈락SECOM 1,567행 → 데이터 부족, 해석성 떨어짐
로지스틱 회귀❌ 탈락비선형 관계 캡처 부족, MCC 0.5 이하

🔍 XAI 선정

XAI 기법적합도판단
SHAP ⭐✅ 선정게임이론 기반 공정 분해, Waterfall + Top-K 텍스트 자동 생성
LIME탈락샘플마다 다른 근사 모델 — 일관성 부족
Permutation Importance탈락전역만 — 개별 샘플 설명 불가
Attention 가중치탈락딥러닝 한정, XGBoost 미적용

📊 Western Electric Rules — 왜 추가했는가

단일 점 임계값(threshold) 방식은 "작은 시프트"를 놓침. WER 4종 룰로 패턴 감지 → Shewhart 대비 5~10배 빠른 이상 감지 (출처: jmp.com CUSUM 비교).

4. 플랫폼 — 4영역 통합 7페이지

🛡️ 품질 (Quality)

P1 실시간 예측 + P2 SHAP 원인 분석 (3계층: 글로벌/Waterfall/Dependence)

🚨 안전 (Safety)

메인 상단 3단계 알림 배너 + Western Electric Rules 자동 감지

P5 SPC 관리도 (UCL/LCL/±σ 보조선) + 센서 분포 임계 마킹

📈 생산 (Production)

P4 이력 누적 + 조치 효과 추적 + Pareto 80/20 우선순위

7. Q&A 심층 답변 10개

  1. Q. 왜 SHAP? A. 게임이론 기반 공정 분해. 각 센서 기여도를 "센서_003이 45% 영향" 같은 한국어 텍스트로 자동 변환 → 비전문가 작업자도 즉시 이해.
  2. Q. 왜 XGBoost? A. 591센서 표 형식 + 6.6% 극심한 불균형에 강건. 5-Fold CV MCC 0.98±0.01. 트리 기반이라 SHAP 자연 결합. 학습 5분 내 가능.
  3. Q. SMOTE 부작용? A. SMOTE는 train에만 적용 (test는 원본 분포 유지) → 검증 신뢰성 보존. scale_pos_weight 동적 조정으로 보강.
  4. Q. Western Electric Rules 추가 이유? A. 단일 점 3σ 임계값보다 패턴(연속 3점/5점/8점) 감지가 5~10배 빠름. 작은 시프트도 놓치지 않음.
  5. Q. 591개 센서 의미? A. SECOM 데이터셋은 익명화 → 센서 의미는 모름. 우리는 분포·기여도 패턴만 정직하게 사용.
  6. Q. 4영역 통합 정말? A. 단일 데이터 소스(timestamp+state)로 7페이지 일관. 사이드바 자유 이동 시 mode 보존(PR-7 session_state fix).
  7. Q. 중소공장이 정말 쓸 수 있나? A. 📤 데이터 업로드 페이지에서 자기 CSV 한 번 → 30초 내 첫 인사이트. 591개 컬럼 부족해도 자동 정렬. UTF-8/CP949 자동 감지.
  8. Q. 모델 드리프트는? A. 본 MVP는 정적 모델. 본선 후 P-D 로드맵에 KS test + PSI 기반 드리프트 모니터링 포함.
  9. Q. 시연 영상은? A. 5분 시나리오(정상→이상→SHAP→조치→복귀). docs/presentation/demo_video_guide.md 가이드 기반.
  10. Q. 향후 확장성? A. 591센서 추상화 → 반도체 식각, 자동차 도장, 식품 공정 등 산업 확장. Claude↔Codex 하이브리드(HANDOVER 50줄) 협업 인프라 검증됨.
