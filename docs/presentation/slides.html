2. AI 활용 — 왜 XGBoost + SHAP?

5/16

🔧 XGBoost 선정 이유

  • 제조 데이터 특성: 591개 센서 표 형식 + 6.6% 극심한 불균형
  • 해석성: 트리 모델 → SHAP 자연 결합
  • 학습 속도: 본선장 5분 내 재학습 가능 (필요 시)
  • 검증 결과: 5-Fold CV MCC = 0.98 ± 0.01

⚖️ 불균형 처리

SMOTE 오버샘플링으로 train 6.6% → 50%.
scale_pos_weight 동적 조정.

🔍 SHAP 선정 이유

  • 게임이론 기반: 각 센서 기여도 공정 분해
  • Top-K 텍스트화: "센서_003이 45% 영향" 자동 한국어 변환
  • Waterfall: base → 누적 → 최종 logit 시각화
  • 본선 호환: 사전 계산 후 캐싱 → 시연 시 재계산 X

🚫 회피한 것

UMAP/t-SNE 임베딩, 딥러닝, 5Why NLP — 모두 "이름만 모름" 패턴으로 작업자 신뢰 떨어짐.

모델 카드: models/model_card_dummy.md Slide 5/16

2. AI 활용 — Threshold Engine + Western Electric Rules

6/16

🎚️ Threshold Engine

  • 운영 임계값: Youden's J 기반 자동 산출 (model_card 명시)
  • 센서별 정상 범위: PASS 데이터의 mean ± 2σ → threshold_table.csv (591 센서)
  • 3단계 신호등: 0.30/0.50 임계값 → 🟢 정상 / 🟡 주의 / 🔴 위험

📊 Western Electric Rules — 패턴 기반 이상 감지

Rule조건감지 대상
Rule 11점이 ±3σ 초과명백한 이상 (즉시)
Rule 2연속 3점 중 2점이 ±2σ 초과시프트 시작 (조기 감지)
Rule 3연속 5점 중 4점이 ±1σ 초과점진적 변화 (트렌드)
Rule 4연속 8점이 중심선 한 쪽평균 이동 (구조 변화)

→ Shewhart 단일 차트보다 5~10배 빨리 작은 시프트 감지. 숙련도 낮은 작업자도 패턴을 놓치지 않음.
