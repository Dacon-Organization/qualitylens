# model-routing — 모델 선택 결정 표

## 결정 규칙

작업이 들어오면 아래 5가지 질문에 답하고, "예"가 1개라도 있으면 한 단계 위 모델로 올린다.

1. 알고리즘이나 평가 지표를 새로 설계해야 하는가?
2. SHAP 결과를 비즈니스 언어로 해석해야 하는가?
3. 멀티 파일 간 일관성 검증이 필요한가?
4. 디버깅에서 근본 원인 파악이 필요한가? (단순 try/except가 아닌 경우)
5. 보안·성능 트레이드오프 결정이 필요한가?
