# prompt-templates — Claude ↔ Codex 동일 템플릿

> 같은 작업은 같은 옷을 입힌다. Claude에서 검증된 프롬프트를 Codex에서도 그대로 사용.

## T-01: 단일 페이지 수정

```
[목표]
{페이지 파일 경로}의 {위젯·차트명}을 {변경 내용}으로 수정.

[제약]
- 동일 파일 내에서만 수정
- 다른 파일·전역 상태에 영향 없음
- st.cache_data 정책 유지
- 차트 스타일: skills/ui/chart-style.md 준수

[검증]
- streamlit run app/app.py 로컬 실행 후 해당 페이지 정상 렌더 확인
```

## T-02: 모델 결과 해석

```
[목표]
다음 SHAP 상위 기여 센서를 비즈니스 언어로 1단락 설명.

[입력]
{shap_top20.csv 발췌 5~10줄}

[출력 형식]
- 첫 문장: 어떤 공정 단계 센서가 가장 큰 영향
- 두 번째 문장: 어떤 방향(과열/저온/진동 등)으로 이상
- 세 번째 문장: 권고 조치 1줄
```

## T-03: 데모 시나리오 점검

```
[목표]
docs/demo_script.md 의 {N분 ~ N+1분} 구간을 다음 조건으로 검증.

[검증 항목]
1. 5분 안에 끝나는지(누적 시간)
2. 화면 전환이 명확한지
3. 청중 이해 곡선이 자연스러운지

[출력]
- 합격/불합격 + 1줄 사유
```

## T-04: 디버그 (근본 원인)

```
[목표]
{에러 메시지}의 근본 원인 식별.

[참조]
- skills/quality/testing.md
- 관련 파일 1개만 첨부 (멀티 파일 첨부 금지)

[출력 형식]
1. 가설 (3개)
2. 가장 가능성 높은 가설 + 근거
3. 수정 코드 (diff 형식)
```
