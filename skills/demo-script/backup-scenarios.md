# backup-scenarios — 백업 시나리오 2종

## 백업 1: Streamlit 정상, 모델 로드 실패

**증상**: 페이지는 뜨지만 `joblib.load()` 에러로 예측 결과 안 나옴.

**대응**:
1. 사이드바 → "데모 (결정론)" 모드로 즉시 전환
2. 데모 모드는 사전 캐싱된 결과(`demo_result.csv`)만 표시
3. 청중에게는 "데모 모드로 시연하겠습니다" 한 마디로 자연스럽게 진행
4. P2~P5 모두 사전 결과로 정상 작동

**준비물**: `data/processed/demo_result.csv`, `data/processed/shap_demo.png`

## 백업 2: Streamlit 자체가 실행 안됨

**증상**: `streamlit run` 명령 자체가 실패. 의존성 충돌 등.

**대응**:
1. PDF 백업 슬라이드로 전체 발표 진행 (사전 export 필수)
2. "현장 환경 이슈로 데모는 슬라이드로 진행하겠습니다"
3. 슬라이드에 P1~P5 스크린샷 8장 사전 삽입
4. 평가 항목 / 차별점 / 확장성에 시간 더 배분 (시연 시간 1분 절약)

**준비물**:
- `docs/QualityLens_발표.pdf` (Streamlit 스크린샷 포함 슬라이드)
- USB 백업 사본

## 비상 신호 (발표자 본인)

| 시점 | 행동 |
|---|---|
| 1분 경과 알람 | 문제 정의 1분 안에 끝났는지 자체 점검 |
| 3분 경과 알람 | P3 원인 분석 도달 못했으면 페이지 건너뛰기 |
| 4분 30초 알람 | 즉시 마무리 슬라이드로 전환, Q&A 준비 |
