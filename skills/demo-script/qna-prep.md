# qna-prep — Q&A 예상 질문 5선

## Q1. "MCC를 평가 지표로 선택한 이유는?"

**A**: SECOM 데이터셋은 불량률 6.6%로 불균형이 심합니다. Accuracy는 다수 클래스에 편향되고, F1도 양 클래스 가중을 고려하지 못합니다. MCC는 4가지 confusion matrix 값을 모두 사용해 불균형에서도 신뢰할 수 있는 단일 지표입니다.

## Q2. "591개 센서 전부 사용했나요? 차원 축소는?"

**A**: 분산 0에 가까운 센서를 제거하고, 상관 0.95 이상 쌍에서 한쪽을 제거해 약 200~250개로 축소했습니다. PCA는 SHAP 해석성을 떨어뜨려 사용하지 않았습니다. 운영형 MVP는 "어느 센서가 문제인지" 가 핵심이라 원본 피처 공간을 유지했습니다.

## Q3. "실제 공장 도입 시 가장 큰 장벽은?"

**A**: 세 가지입니다.
1. 데이터 라벨링 — PASS/FAIL 라벨이 신뢰할 수 있어야 합니다
2. 센서 드리프트 — 시간에 따른 정상 범위 재학습 주기
3. 작업자 신뢰 — SHAP 설명이 현장 언어로 번역되어야 함
이 중 3번을 위해 **조치 가이드(P4)** 를 핵심 기능으로 넣었습니다.

## Q4. "XGBoost 외 다른 모델은 비교했나요?"

**A**: LightGBM, Random Forest, Logistic Regression을 비교했고 MCC 기준 XGBoost가 가장 안정적이었습니다. 또한 SHAP TreeExplainer가 추론 속도와 해석성 양쪽에서 균형이 좋아 XGBoost를 채택했습니다.

## Q5. "확장한다면 다음 단계는?"

**A**: 세 가지 방향입니다.
1. **다공정 확장** — 현재는 단일 공정. Multi-task 학습으로 공정별 헤드 분리
2. **이상 유형 분류** — 단순 PASS/FAIL → 이상 카테고리(과열·진동·재료 결함)
3. **자율 조치 연동** — 권고 → PLC 자동 제어 (단, 안전 검증 필수)
